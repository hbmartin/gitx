# Render commit flow deltas in a native History Flow tab

GitX will present FlowDelta's per-commit control-flow and data-flow delta in a third History tab, **Flow**, beside Details and Tree in `PBGitHistoryView.xib`. `PBGitHistoryController` owns the tab through a thin `@objc` adapter (ADR 0007), and the selected tab persists alongside the existing `kHistorySelectedDetailIndexKey` mechanism. The Flow view carries its own co-present read-only source pane synchronized with graph selection rather than reusing the Details pane's `PBNativeContentView`; that view's accessory slot remains dedicated to the pull-request review overlay.

Rendering is pure AppKit and Core Animation, extending ADR 0001's native-rendering doctrine to graph content: an `NSView` host owns a CALayer scene graph — `CAShapeLayer` edges plus layer-backed node views for hit-testing, context menus, and accessibility — positioned by FlowDelta's deterministic layout, with staged delta transitions expressed as explicit `CAAnimation`s keyed on stable block identities. SwiftUI hosted in `NSHostingView` was rejected because the codebase contains no SwiftUI and runs MainActor-default strict concurrency inside XIB-instantiated Objective-C controllers, making graph rendering a poor place to introduce a second UI paradigm; WebKit was rejected because ADR 0001 removed it deliberately. If profiling ever demands more than Core Animation provides, the layer tree ports to `MTKView` without changing the view's public surface.

[FlowDelta 0.1.0](https://github.com/hbmartin/FlowDelta/tree/0.1.0) satisfies the Swift-only M1 exit gate with a stable superimposed CFG delta view, native source synchronization, staged transitions, control-context causality, and the validation evidence recorded in its [M1 validation record](https://github.com/hbmartin/FlowDelta/blob/0.1.0/notes/006-m1-validation.md). The History Flow tab still ships in M2 alongside FlowDelta's multi-language milestone. Until then the History view keeps its current two tabs; this ADR does not add a package pin or application integration.
